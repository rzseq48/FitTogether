# Update Iterations

Use this folder to showcase the progression of each project update.

Suggested structure:
- one subfolder per update, such as `update-01/` or `2026-03-26-home-refresh/`
- screenshots, screen recordings, mockups, or notes that capture each iteration
- a short `README.md` inside each update folder describing what changed

Example:

```text
artifacts/update-iterations/
├── 2026-03-26-home-refresh/
│   ├── README.md
│   ├── before.png
│   ├── after.png
│   └── notes.md
└── 2026-03-27-food-flow-tuning/
    ├── README.md
    └── iteration-1.png
```

Keep source code out of this folder and store only showcase material for review, demos, or progress tracking.
